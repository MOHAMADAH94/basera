# بصيرة - تطبيق تعليمي للمكفوفين

تطبيق تعليمي شامل للمكفوفين يعتمد على المحتوى الصوتي والتفاعل الصوتي الكامل دون الحاجة للشاشة.

## 🌟 الميزات الرئيسية

### 🎙️ 1. تحويل الصوت إلى نص (Speech-to-Text)
- تسجيل الدروس صوتيًا
- تفريغ تلقائي دقيق للنص مع دعم العربية
- إمكانية مراجعة النص من قبل متطوعين
- تقسيم النص إلى فقرات وعناوين ونقاط تعليمية

### 🔊 2. قراءة النص صوتيًا (Text-to-Speech)
- قراءة المحتوى بصوت واضح
- التحكم في سرعة القراءة ونبرة الصوت
- اختيار لهجة (عربية فصحى / لهجة محلية)

### 🧭 3. التنقل الصوتي الكامل
- أوامر صوتية: "التالي"، "أعد الفقرة"، "اذهب للدرس السابق"
- ردود صوتية فورية
- تفاعل كامل دون الحاجة لملامسة الشاشة

### 📚 4. مكتبة صوتية منظمة
- تصنيفات متنوعة:
  - تعليم القراءة والكتابة
  - القرآن والتجويد
  - لغات
  - مهارات حياتية
  - تعليم تقني (أساسيات الحاسوب، الهاتف)

### 📝 5. اختبارات صوتية
- أسئلة تُقرأ صوتيًا
- إجابات صوتية من المستخدم
- تقييم تلقائي أو بمراجعة بشرية

### 🤝 6. دور المتطوعين
- واجهة خاصة للمتطوعين
- مراجعة التفريغ الصوتي
- تصحيح الأخطاء
- إضافة شروحات مبسطة
- تسجيل محتوى جديد

### 🧠 7. تلخيص صوتي ذكي
- تلخيص الدروس تلقائيًا
- تحويل الدرس إلى نقاط مختصرة
- مراجعة سريعة قبل الاختبار

### 🔍 8. البحث الصوتي
- البحث داخل المحتوى صوتيًا
- "ابحث عن درس عن الجمع"
- "أين وردت كلمة كذا؟"

### 📶 9. العمل بدون إنترنت
- تحميل الدروس مسبقًا
- تشغيل المحتوى أوفلاين

## 🛠️ التقنيات المستخدمة

### Backend (Django)
- Django 5.0
- Django REST Framework
- SQLite (قابل للتغيير إلى PostgreSQL)
- Whisper للتفريغ الصوتي (اختياري)

### Frontend (Flutter)
- Flutter 3.7+
- Speech-to-Text
- Flutter TTS
- Audio Players
- Riverpod للـ State Management
- HTTP/Dio للاتصال بالـ API

## 📦 التثبيت والإعداد

### متطلبات النظام
- Python 3.10+
- Flutter SDK 3.7+
- Node.js (للمطورين)

### إعداد Backend

1. الانتقال إلى مجلد Backend:
```bash
cd backend
```

2. إنشاء بيئة افتراضية:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# أو
venv\Scripts\activate  # Windows
```

3. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

4. إعداد قاعدة البيانات:
```bash
python manage.py makemigrations
python manage.py migrate
```

5. إنشاء مستخدم إداري:
```bash
python manage.py createsuperuser
```

6. تشغيل السيرفر:
```bash
python manage.py runserver
```

### إعداد Frontend

1. الانتقال إلى مجلد المشروع:
```bash
cd .
```

2. تثبيت المتطلبات:
```bash
flutter pub get
```

3. تشغيل التطبيق:
```bash
flutter run
```

## 🔧 الإعدادات

### إعدادات Backend

في ملف `backend/basera_backend/settings.py` يمكنك تعديل:
- `SECRET_KEY`: مفتاح سري للـ Django
- `DEBUG`: وضع التطوير/الإنتاج
- `ALLOWED_HOSTS`: المضيفات المسموحة
- `DATABASES`: إعدادات قاعدة البيانات

### إعدادات Frontend

في ملف `lib/config/app_config.dart` يمكنك تعديل:
- `baseUrl`: عنوان الـ API
- `defaultSpeechRate`: سرعة القراءة الافتراضية
- `defaultPitch`: نبرة الصوت الافتراضية

## 📱 استخدام التطبيق

### للمستخدمين (الطلاب)
1. تسجيل الدخول أو إنشاء حساب جديد
2. تصفح التصنيفات صوتيًا
3. اختيار درس للاستماع
4. استخدام الأوامر الصوتية للتنقل
5. إجراء الاختبارات الصوتية

### للمتطوعين
1. تسجيل الدخول بحساب متطوع
2. مراجعة التفريغات الصوتية
3. تصحيح الأخطاء وإضافة شروحات
4. رفع محتوى صوتي جديد

## 🎯 الأوامر الصوتية المدعومة

- "التالي" - الانتقال للعنصر التالي
- "السابق" - الانتقال للعنصر السابق
- "أعد" - إعادة تشغيل/قراءة
- "توقف" - إيقاف مؤقت
- "استمر" - متابعة
- "الرئيسية" - العودة للصفحة الرئيسية
- "الخلف" - العودة للخلف
- "ابحث عن..." - البحث في المحتوى
