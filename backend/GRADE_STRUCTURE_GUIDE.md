# دليل الهيكل الهرمي: الصفوف → المواد → الدروس

## الهيكل

```
صف دراسي (Grade)
  └── مادة دراسية (Category/Subject)
       └── درس (Lesson)
```

## مثال:
```
صف تاسع (Grade)
  ├── الرياضيات (Category)
  │    ├── درس 1: الجبر
  │    ├── درس 2: الهندسة
  │    └── درس 3: الإحصاء
  ├── اللغة العربية (Category)
  │    ├── درس 1: النحو
  │    └── درس 2: البلاغة
  └── العلوم (Category)
       └── درس 1: الفيزياء
```

## كيفية الاستخدام

### 1. إضافة صف دراسي جديد

1. اذهب إلى **Django Admin** → **Lessons** → **الصفوف الدراسية**
2. اضغط **إضافة صف دراسي**
3. املأ:
   - **اسم الصف**: مثال "صف تاسع" أو "الصف التاسع"
   - **الوصف**: (اختياري)
   - **ترتيب العرض**: رقم (0 للصف الأول)
   - **نشط**: ✓
4. اضغط **حفظ**

### 2. إضافة مادة داخل الصف

1. اذهب إلى **Lessons** → **المواد الدراسية**
2. اضغط **إضافة مادة دراسية**
3. املأ:
   - **الصف الدراسي**: اختر الصف من القائمة
   - **اسم المادة**: مثال "الرياضيات"
   - **الوصف**: (اختياري)
   - **أيقونة**: (اختياري)
   - **ترتيب العرض**: رقم
   - **نشط**: ✓
4. اضغط **حفظ**

### 3. إضافة درس داخل المادة

1. اذهب إلى **Lessons** → **الدروس**
2. اضغط **إضافة درس**
3. املأ:
   - **عنوان الدرس**: مثال "درس الجبر"
   - **المادة الدراسية**: اختر المادة (التي تنتمي لصف معين)
   - **الملف الصوتي**: ارفع الملف
   - **الحالة**: اختر "منشور" لعرضه
4. اضغط **حفظ**

## API Endpoints

### الصفوف:
- `GET /api/lessons/grades/` - قائمة الصفوف
- `GET /api/lessons/grades/{id}/` - تفاصيل صف
- `GET /api/lessons/grades/{id}/subjects/` - مواد الصف

### المواد:
- `GET /api/lessons/categories/` - قائمة المواد
- `GET /api/lessons/categories/?grade={grade_id}` - مواد صف معين

### الدروس:
- `GET /api/lessons/` - قائمة الدروس
- `GET /api/lessons/?category={category_id}` - دروس مادة معينة

## ملاحظات

- يجب حذف التصنيفات القديمة التي لا تحتوي على صف وتعديلها يدوياً
- تأكد من ربط كل مادة بصف دراسي
- استخدم **ترتيب العرض** لتنظيم الصفوف والمواد
- الحالة **منشور** مطلوبة لعرض الدرس للمستخدمين
