# ملاحظات مهمة للـ Migration

## ⚠️ تنبيه

تم جعل حقل `grade` في `Category` nullable مؤقتاً للسماح بوجود بيانات قديمة.

## الخطوات المطلوبة:

### 1. حذف التصنيفات القديمة (إن وجدت):
- اذهب إلى Django Admin
- Lessons → المواد الدراسية
- احذف أي مواد لا تنتمي لصف دراسي (grade = null)

### 2. إضافة صفوف جديدة:
- Lessons → الصفوف الدراسية
- أضف الصفوف (مثل: صف تاسع، صف ثامن)

### 3. إضافة مواد مرتبطة بالصفوف:
- عند إضافة مادة جديدة، تأكد من اختيار صف دراسي

### 4. ربط المواد القديمة بصفوف (إن كانت موجودة):
- يمكنك تعديل المواد القديمة وإضافة صف دراسي لها

## بعد إتمام الخطوات أعلاه:

يمكنك جعل `grade` required مرة أخرى عبر:
1. تعديل `models.py` لإزالة `null=True, blank=True`
2. عمل migration جديدة
3. تطبيقها

**أو** يمكنك تركها nullable إذا أردت السماح بمواد عامة (غير مرتبطة بصف معين).
