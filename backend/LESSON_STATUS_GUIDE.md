# دليل حالة الدروس

## المشكلة
الدروس الجديدة تُنشأ بحالة `draft` (مسودة) افتراضياً، لكن API يعرض فقط الدروس بحالة `published` (منشور).

## الحل

### في لوحة الإدارة (Admin Panel):
1. افتح لوحة الإدارة: `http://127.0.0.1:8000/admin/`
2. اذهب إلى **Lessons** (الدروس)
3. اختر الدرس الذي تريد نشره
4. في حقل **Status** (الحالة)، اختر `published` (منشور)
5. احفظ التغييرات

### حالات الدرس:
- **draft** (مسودة): الدرس قيد الإنشاء - **لا يظهر في التطبيق**
- **review** (قيد المراجعة): الدرس قيد المراجعة - **لا يظهر في التطبيق**
- **approved** (معتمد): الدرس معتمد - **لا يظهر في التطبيق**
- **published** (منشور): الدرس منشور - **يظهر في التطبيق** ✅
